# My AI Portfolio

A one-page responsive portfolio built for the Looponics "Build Something With AI" challenge.

## Tools
ChatGPT/Claude for planning and code, Google Stitch for the wireframe, HTML/CSS/JS, GitHub for hosting.

## Run locally
No install needed. Open `index.html` in your browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Deploy
Push to GitHub, then Settings > Pages > deploy from the `main` branch (or drag the folder to Netlify).

## Files
`index.html` (site), `project-plan.md`, `prompts.md`, `testing-report.md`, `screenshots/`.
